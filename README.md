# QuizForge

Self-contained quiz reviewers for STI College Meycauayan BSIT subjects. Each quiz is a single HTML file — open it in any browser, on any device, online or offline. No accounts, no installs.

## Take a quiz

**[→ Open the Reviewer Hub](https://officialraphaelraymundo-wq.github.io/quizforge/)**

New subjects and question batches get added as the semester goes on.

## What you get

- Pick how many questions and which topics to focus on
- Optional timer and exam simulation with pass/fail scoring
- Four question types: single-answer, multi-select, fill-in-the-blank, and scenario-based
- Every wrong answer tells you *why* it's wrong
- Works offline once you have the file

## AI disclosure

Questions are AI-generated from our course handouts using multiple models — one writes, a different one reviews, and a third solves the quiz blind to catch errors. Every batch is validated and manually approved before publishing.

The AI writes the questions. I check them and own the mistakes. If you spot a wrong answer, message me.
